# ⚡ Electric Utility Buggy 2-Seater (RWD, IRS)
> Двухместный утилитарный электробагги с независимой подвеской (IRS), модульной АКБ 72V (50+ км), зимним снегоотвалом и каркасом из профильной трубы **без применения трубогиба**.

## 📂 Структура проекта

* **`electric_buggy.FCStd`** — Полный параметрический 3D-проект для **FreeCAD** с деревом объектов и чертежным листом *TechDraw_Blueprint*.
* **`electric_buggy.blend`** — Полноценная 3D-сцена для **Blender 5.x** со всеми узлами, PBR-материалами, коллекциями, освещением и камерой.
* **`buggy_frame_chassis.obj`** — 3D-модель в формате Wavefront OBJ для импорта в любой CAD/3D-редактор.
* **`viewer.html`** — Автономный интерактивный 3D-просмотрщик на WebGL/Three.js (открывается прямо в браузере).
* **`FABRICATION_AND_ELECTRICAL_GUIDE.md`** — Практическое руководство по сварке рамы, сборке стапеля, электрической схеме 72V/12V, предзаряду (Precharge) и настройке BMS.
* **`calculations.py`** — Инженерный скрипт расчета тяги, скоростей, токов и спецификации проката.
* **`drawings/`** — Комплект подробных рабочих чертежей в векторном формате SVG:
  * `01_frame_assembly.svg` — Общий сборочный чертеж рамы (габариты, проекции, углы резов).
  * `02_front_suspension_arms.svg` — Деталировка передних А-образных рычагов под сайлентблоки и шаровые ВАЗ-2108.
  * `03_rear_irs_arms.svg` — Задняя независимая подвеска IRS со схемой регулировки схождения на рулевом сгоне ВАЗ.
  * `04_powertrain_motor_plate.svg` — Моторная плита QS138 с пазами натяжки цепи и опорами дифференциала UCP206.
  * `05_snow_plow_assembly.svg` — Поворотный отвал 1400 мм с пружинной защитой от ударов и быстросъемом.
  * `06_battery_box_thermal.svg` — Съемный термобокс АКБ 72V с утеплителем ЭППС и подогревом 12V.
  * `07_suspension_corner_assembly.svg` — Угол подвески в сборе (единый на 4 колеса), координаты шарниров.
  * `08_knuckle_adapter_AD01.svg` — Адаптер АД-01 на кулак 2108: верхний ШС + рулевой рычаг.
  * `09_front_subframe_kinematics.svg` — Передний подрамник, графики развала и подруливания.
  * `10_steering_system.svg` — Рулевая трапеция (Аккерман), требования к рейке, колонка.
  * `11_power_module_gearbox.svg` — Силовой модуль QS138 → цепь → КПП 2108 → приводы (заменяет лист 04).
  * `12_brake_system.svg` — Тормозная гидравлика, педальный узел, стояночный тормоз.
  * `13_brackets_hardware.svg` — Кронштейны, имитатор ШРУС, моменты затяжки, прочность рычагов.
* **`chassis_geometry.py`** — Единый источник геометрии шасси: кинематика подвески, пружины, рулевое, тормоза, трансмиссия.
* **`generate_assembly_drawings.py`** — Генератор листов 07–13 из `chassis_geometry.py`.
* **`CHASSIS_ASSEMBLY_GUIDE.md`** — Сборка подвески, рулевого, тормозов и силового модуля; что замерить на доноре.

| **Профтруба 40х40** | 40х40х2.0 мм | 18.0 м | **3 хлыста** (18 м) | Клетка безопасности, дуги, диагонали крыши |

## ⚡ Принципиальная электрическая схема 72V / 12V

```
 [АКБ №1: 72V 48Ah] ---> [Smart BMS 100A] ---> [DC Автомат 100A] ---\
                                                                     +---> [ШИНА ПЛЮС 72V]
 [АКБ №2: 72V 48Ah] ---> [Smart BMS 100A] ---> [DC Автомат 100A] ---/            |
 (опция расширения)                                                              |
                                                                                 v
                                                                  [Главный контактор 72V 200A]
                                                                  (с резистором Precharge 1k 25W)
                                                                                 |
                                                                                 v
 [МАССА МИНУС 72V] <--------------------------------------------------- [Контроллер VOTOL EM150]
        |                                                                        |
        |---> [DC-DC 72V -> 12V 30A]                                             | (3 фазы U,V,W + Холлы)
        |          |                                                             v
        |          v                                                    [Мотор QS138 70H V3]
        |     [Бортовая сеть 12V]
        |     - Подогрев ячеек АКБ (термореле KSD9700 +5°C...+20°C)
        |     - Лебедка подъема отвала 2000 lbs
        |     - LED фары, стоп-сигналы, звуковой сигнал
```

## ❄️ Зимняя эксплуатация и уборка снега

1. **Термобокс с подогревом:** Ячейки NMC утеплены экструдированным пенополистиролом (ЭППС) 20 мм. Внутри установлен греющий мат 12V 40W. При падении температуры ниже +5°C автоматика подогревает ячейки, исключая деградацию лития.
2. **Безопасный отвал 1400 мм:** При наезде на люк, бордюр или вмерзший камень ковш откидывается вперед на нижнем шарнире, растягивая две мощные пружины, перескакивает препятствие и возвращается назад без повреждения рамы.
3. **Подъем отвала:** Осуществляется электрической квадроциклетной лебедкой 12V с управлением тумблером на панели.

## 🚀 Быстрый старт

### 1. Открыть 3D-модель в браузере:
Просто откройте файл `viewer.html` в Google Chrome или Firefox:
```bash
google-chrome viewer.html
```

### 2. Открыть в FreeCAD:
```bash
FreeCAD electric_buggy.FCStd
```

### 3. Открыть в Blender:
```bash
blender electric_buggy.blend
```
